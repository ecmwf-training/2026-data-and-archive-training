# 2026-data-and-archive-training
Repository for ECMWF online training course: Introduction to ECMWF Data and Archive Services

## Setup
To use the materials on your own laptop, create virtual environment:
```
python3 -m venv ./earthkit-venv
source ./earthkit-venv/bin/activate
pip3 install -r ./requirements.txt
```
Above environment can be used for Earthkit part of the course as well.

## Earhtkit
For Earthkit part of this training course go to: [Earthkit 2026 training repository](https://github.com/ecmwf-training/2026-earthkit-training)
